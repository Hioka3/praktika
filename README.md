## Задание 1. Статический массив
**Цель:** Реализовать статический массив с фиксированной емкостью и основными операциями.  
**Методы:** `pushBack`, `pushFront`, `insert`, `remove`, `find`  
**Сложность:** O(1) для pushBack, O(n) для остальных операций  
**Особенности:** Проверка границ массива, ручное управление памятью

## Задание 2. Динамический массив  
**Цель:** Реализовать динамический массив с автоматическим расширением (×2 стратегия).  
**Методы:** Те же что в задании 1 + `_resize`  
**Сложность:** Амортизированная O(1) для добавления  
**Особенности:** Автоматическое расширение при переполнении, сравнение производительности со статическим

## Задание 3. Односвязный список
**Цель:** Реализовать односвязный список с основными операциями.  
**Методы:** `pushFront`, `pushBack`, `remove`, `find`, `reverse`  
**Сложность:** O(1) для вставки в начало, O(n) для поиска  
**Особенности:** Разворот списка in-place, сравнение с массивом

## Задание 4. Двусвязный список
**Цель:** Реализовать двусвязный список с двунаправленными ссылками.  
**Методы:** `pushBack`, `insertAfter`, `removeNode`, `find`, итератор  
**Сложность:** O(1) для удаления узла без поиска  
**Особенности:** Удаление по ссылке на узел, двунаправленный обход

## Задание 5. Стек
**Цель:** Реализовать стек на массиве и связном списке.  
**Методы:** `push`, `pop`, `peek`, `isEmpty`  
**Сложность:** O(1) для всех операций  
**Особенности:** Проверка скобочных последовательностей, две реализации

## Задание 6. Очередь
**Цель:** Реализовать очередь на циклическом массиве и двух стеках.  
**Методы:** `enqueue`, `dequeue`, `peek`, `isEmpty`  
**Сложность:** O(1) амортизированная  
**Особенности:** Циклический буфер, реализация через два стека

## Задание 7. Калькулятор
**Цель:** Реализовать калькулятор выражений в инфиксной форме.  
**Методы:** `infixToRPN`, `evaluateRPN`, `calculate`  
**Сложность:** O(n) для преобразования и вычисления  
**Особенности:** Преобразование в обратную польскую нотацию, поддержка приоритетов операций

## Задание 8. Хэш-таблица
**Цель:** Реализовать хэш-таблицу с цепочками для разрешения коллизий.  
**Методы:** `put`, `get`, `remove`, `_hash`, `visualize`  
**Сложность:** O(1) в среднем случае  
**Особенности:** Автоматическое рехеширование, визуализация состояния

## Задание 9. Частотный словарь
**Цель:** Построить частотный словарь слов в тексте.  
**Методы:** `build_with_hash`, `build_with_counter`, `get_top_words`  
**Сложность:** O(n) для построения  
**Особенности:** Сравнение разных хэш-функций, топ-10 частых слов

## Задание 10. Trie + HashMap для автодополнения
**Цель:** Реализовать префиксное дерево с автодополнением.  
**Методы:** `insert`, `autocomplete`, `get_suggestions_by_frequency`  
**Сложность:** O(m) для поиска по префиксу (m - длина префикса)  
**Особенности:** Подсказки по частоте использования, комбинация Trie и HashMap

## Задание 11. Бинарное дерево поиска (BST)
**Цель:** Реализовать сбалансированное бинарное дерево поиска.  
**Методы:** `insert`, `search`, `delete`, обходы (in-order, pre-order, post-order)  
**Сложность:** O(log n) для операций в сбалансированном дереве  
**Особенности:** Проверка балансировки, AVL-подобные вращения

## Задание 12. Расширенный Trie
**Цель:** Расширить функциональность префиксного дерева.  
**Методы:** `starts_with`, `delete`, `get_word_count`, `get_stats`  
**Сложность:** O(m) для операций (m - длина слова)  
**Особенности:** Подсчет вариантов по префиксу, удаление слов, статистика

## Задание 13. Графы
**Цель:** Реализовать представления графов и основные алгоритмы.  
**Методы:** `bfs`, `dfs`, `shortest_path_unweighted`, матрица и список смежности  
**Сложность:** O(V + E) для обходов  
**Особенности:** Два представления графа, поиск кратчайшего пути в невзвешенном графе

## Задание 14. Острова
**Цель:** Найти количество островов в бинарной матрице.  
**Методы:** `count_islands_dfs`, `count_islands_bfs`, `get_island_sizes`  
**Сложность:** O(rows × cols)  
**Особенности:** Поиск компонент связности, обход в глубину и ширину

## Задание 15. Бинарная мин-куча
**Цель:** Реализовать бинарную мин-кучу.  
**Методы:** `insert`, `extract_min`, `build_heap`, `is_valid_heap`  
**Сложность:** O(log n) для вставки и извлечения  
**Особенности:** Построение кучи из массива, проверка свойств кучи

## Задание 16. Приоритетная очередь
**Цель:** Реализовать приоритетную очередь на основе кучи.  
**Методы:** `push`, `pop`, `task_scheduling`, `find_k_smallest`  
**Сложность:** O(log n) для вставки и удаления  
**Особенности:** Планирование задач, поиск k минимальных элементов
